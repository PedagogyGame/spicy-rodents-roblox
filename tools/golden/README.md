# tools/golden: golden vectors from the original v5.4 functions

Runs byte-exact copies of the v5.4 functions (lifted from `reference/v5_4_game.js` by line range)
in Node with `three@0.160.1` from npm and writes fixed, seeded input/output vectors to
`data/golden/*.json`. The Luau ports (`World/Height`, `Routes/Curve`, `Routes/Motion`,
`Traffic/Swept`, `Combat/CombatRules`, `Actors/Perception`) must reproduce them (BUILD_PLAN 6.2, 6.3).
Also writes `docs/reports/golden_report.md`.

## Run

```bash
# one-time: install three@0.160.1 (npm registry is reachable; cache under /root/.cache/npm)
cd tools/golden && npm_config_cache=/root/.cache/npm npm install --no-audit --no-fund

# generate (about 5 s); needs data/harvest/routes.json and route_samples.json from tools/harvest
node tools/golden/src/golden.js
node tools/golden/src/golden.js --reference /home/user/spicy-rodents/reference/v5_4_game.js \
  --harvest data/harvest --out data/golden --report docs/reports/golden_report.md

# regenerate src/original.js from the reference (only needed if the block table changes)
python3 -I tools/golden/gen_original.py
```

The run fails if any verbatim block in `src/original.js` no longer matches the reference lines
(SHA-256 per block), or if the harvest files are missing.

## What is verbatim and what is glue

`src/original.js` is GENERATED by `gen_original.py`: each block is the exact text of the cited lines
(`rng` L80-89, `RouteMotion` L267-272, `smoothstep` L403-406, `baseTerrainHeight` L407-416, `RIVER`
L419-435, river functions L436-457, `terrainHeight` L458-464, `hedgePatches` L3573-3579, `GARDEN_X/Z`
L3590-3591, `RouteJunction` L5782-5793, `attackHeading` L5900-5906, `jumpVelocity` L5915-5921,
`SQUIRREL_GRAVITY` L6472, `pounceVelocity` L6473-6481, the `spotted` statements L7027-7051,
`segmentBoxEntry` L15786-15807, `sweptVehicleHit` L15808-15851). The glue is the module-level state
those functions read from the game scope (`player`, `pitch`, `activeHouseInterior`, `time`,
`crimeScenes`), the `v()` helper (L94) and a wrapper that returns the spotted intermediates.

Catmull-Rom comes from the npm `three` package. `golden.js` rebuilds all 1,332 harvested routes with
it and compares against the harvest (inlined r160): max length difference 6e-14, max sample point
difference 3e-13, so the two builds are the same curve code.

## Outputs (`data/golden/`)

Large sets use `columns` + `rows` (one row per line) to stay compact; small sets use objects.
Non-finite numbers are encoded as the strings `"NaN"`, `"Infinity"`, `"-Infinity"`. All random draws
use the game's own `rng(seed)`; seeds are in each file and in `manifest.json`.

| file | rows | what |
|---|---|---|
| `terrain.json` | ~11k | base/terrain height, river centre, district/water flags, bridge deck on a 20 u grid plus seeded random, river, bridge, water-edge and exact boundary points |
| `curves.json` | 200 routes | control points, `getLength`, `getLengths(200)`, `getSpacedPoints(steps)`, and `getUtoTmapping`/`getPoint`/`getPointAt`/`getTangentAt` at 31 t values |
| `advance.json` | 2,000 | `RouteMotion.advance` incl. dt clamp and short routes |
| `rail_motion.json` | 60 x 40 | sequences of advance + clamp + `getPointAt`/`getTangentAt` along real routes at the spec rail speeds |
| `swept.json` | 10,126 | 126 hand cases + 10,000 seeded `sweptVehicleHit` cases over the six fleet boxes (4,715 hits) |
| `segment_box_entry.json` | 3,000 | the slab test alone, incl. axis-parallel and zero-length segments |
| `travel_filter.json` | 72 | the `finishTrafficFrame` travel filter thresholds |
| `pounce.json` | 5,200 | `attackHeading`, `pounceVelocity`, `jumpVelocity` over an exhaustive grid |
| `spotted.json` | 3,010 | 10 hand cases + 3,000 seeded cases with every intermediate boolean |
| `junction.json` | 49 | `RouteJunction.inward/canTransfer/ease` at the thresholds |
| `manifest.json` | | three version, verbatim block hashes, cross-check numbers, seeds, file hashes |

BUILD_PLAN 6.3 names `tests/golden/`; this tool writes to `data/golden/` (the path assigned to it).
Moving the directory needs no other change.

## Files

- `gen_original.py` writes `src/original.js` from the reference
- `src/original.js` the verbatim blocks plus glue and `verifyVerbatim()`
- `src/golden.js` the vector generator and report writer
- `src/jsonfmt.js` deterministic JSON writer (numeric rows on one line)
