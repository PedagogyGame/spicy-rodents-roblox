boxes. Fallbacks: D1 "blink handoff", D3 standard replication; decided at G0.

2. `rojo build places/s2/default.project.json -o build/s2.rbxl` (298 KB) -> `save_place --place ci` (v10) ->
   `run_engine_tests tools/cloud/tasks/possession_s2_smoke.luau --version 10 --place ci` (one task: the
   place smoke, then the soak; 4.5 s end to end). Results: `build/s2_smoke.json` (not committed).
3. The soak picks a random stub player each op: join (RoleService gives a free human), take a free
   body (a swap if already driving), release, recover, leave (RoleService release-first), or try to
   take a body someone else drives (must be refused); 1-3 AI frames (1/60 s, LoopWalker + `BulkMoveTo`
   on AI roots) after each op; `Possession:check()` after every op. Stub engine: `Character` and
   `SetNetworkOwner(player)` are recorded (Luau Execution has no players), but every handoff calls the
   real `CanSetNetworkOwnership()` before granting and the real `SetNetworkOwner(nil)` on release.

## Findings

- **Rollback matters.** Any failure between unanchoring and `Character = body` (e.g. an anchored
  root, a destroyed part) now returns the body to AI with the brain resumed; a Lune case forces it.
- **Stream first, then re-validate.** `RequestStreamAroundAsync` is the only yield in a handoff; the
  body can be taken while it yields, so possess re-checks after it (counted as a refusal).
- **D3 needs the server to strip Animators.** The S7 puppet ships with a server-side Animator and a
  Script; `prepareBody` removes both so every client makes its own Animator and no track replicates.
- **Squirrel bodies are kinematic on their owner too:** collision off on every puppet part, root
  written each PreSimulation with a local anti-gravity force. W1's SquirrelMotor (S3) drops in behind
  the same `start/stop`.
- `CreateHumanoidModelFromDescription` with a blank description is fast enough to build bodies at boot
  (3 ms each).
