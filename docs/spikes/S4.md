# S4 — Fatal traffic (server swept collision) — VERDICT: GO

**Question.** Can v5.4's run-over test be ported bit-exactly and run on the server every tick for every squirrel actor against the whole fleet within budget?

**Built:**
- `src/shared/Traffic/Swept.luau`: a statement-for-statement port of `segmentBoxEntry` and `sweptVehicleHit` (L15786–15851), including V8's `Math.hypot` and the travel filter.
- `src/shared/Traffic/LaneMath.luau`: lane poses, wrap and ping-pong, `vehicleAhead`.
- `src/server/Traffic/SweptCollision.luau`: a per-tick service with boxes per vehicle kind, a teleport flag, first hit wins, and a broad phase.

**Measured vs pass criteria:**

| Criterion | Target | Result |
|---|---|---|
| Golden swept (126 hand + 10,000 random) | 100 % | **10,126 / 10,126, 4,715 hits** |
| segmentBoxEntry 3,000, travel filter 72 | match | **pass** |
| Broad phase | never rejects a true hit | **0 false rejects**, prunes 2,255 of 5,411 misses |
| 1,000 randomised crossings vs an independent dense-sampling oracle | 100 % | **1,000 / 1,000** (162 hits) |
| Sedan jump window (traffic.md §8.4: 0.514 s computed) | ≈ 0.51 s | **0.500 s** at 60 Hz quantisation, parked and at 6 u/s; never hit while above the ceiling |
| Cost, 15 squirrels × 50 vehicles | ≤ 0.5 ms / tick | Lune **0.18–0.21 ms**; **engine 0.30 ms avg, 0.36 ms max** (CI v3, `tools/cloud/tasks/spike_s3_s4_perf.luau`) |

**Finding: Lune's JSON decoder is not round-trip exact.** It can be off by one ulp, and that flipped three near-180° turn cases. Golden tests that need bit-exactness use `tests/lib/PreciseJson.luau`. Other golden tests use tolerances and are unaffected.
