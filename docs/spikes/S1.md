## What did not pass, and why

**Saving a place version is refused by the key, on both routes:**

- Assets API `PATCH /assets/v1/assets/118507593202954` (published=false): **403
  `PERMISSION_DENIED` "User not authenticated"**. The same 403 comes back for a plain read
  (`GET /assets/v1/assets/{id}`) on the CI, main and Art Inbox places, so the key has no `assets`
  permission at all (the `cloud/v2` reads prove it is injected and valid).
- Legacy `POST /universes/v1/{u}/places/{p}/versions?versionType=Saved`: **403 "Scope not
  authorized."** (needs `universe-places:write`).

PROJECT_IDS.md records both scopes as granted; the live key disagrees. The most likely cause is
that the Assets permission was added for the duplicate experience "Spicy Rodents" (universe
10775476357) rather than "Spicy Rodent" (10775476638), or that the key was edited after the
Luau-execution fix without re-adding Assets. This is **owner step OS-0b** (about 2 minutes on
create.roblox.com -> Open Cloud -> API Keys): add **Assets: Read + Write** for the experience
"Spicy Rodent", and optionally **Universe Places: Write**. Then the lead runs the three commands at
the end of `tools/cloud/README.md`; the expected end-to-end time is the upload plus about 4 s.

Consequences while it is open: `save_place`, `upload_asset` (S7, S8a, S8f need it) and `publish`
(S11) cannot run. Luau Execution and all reads work.

## New finding: engine tests without a save (`--inject`)

A Luau Execution task may create ModuleScripts, set their `Source` and `require` them (tested:
`canSetSource = true, canRequire = true`). `tools/cloud` therefore rebuilds the Rojo code tree
inside the task from the project file (174 instances for the W0 skeleton) and then runs the suite.
This is how BootSmoke passed above against the stock version 1. Limits: the script counts against
the 4 MB task cap (76 KB today), content files (`.rbxm`, `.model.json`) are not injected, and the
NotScriptable project properties cannot be applied (nor read by any script; see below). It is a
good fit for `BootSmoke`, `DataIntegrity`, pure-logic suites and `Actors`-style tests; `WorldBuild`
against a baked `Town.rbxm` still wants a real saved version.

## Other facts learned

- **Lune cannot be the HTTP client here.** `@lune/net` ignores `HTTPS_PROXY` and the proxy does
  DNS, so requests fail with "failed to lookup address information". Node 22.23's built-in fetch
  with `NODE_USE_ENV_PROXY=1` works (and `curl` does), so `tools/cloud` is dependency-free Node.
- **NotScriptable properties.** `Workspace.ModelStreamingBehavior`, `PlayerCharacterDestroyBehavior`,
  `SignalBehavior` and `Lighting.Technology` raise "not a valid member" when a script reads them,
  in Luau Execution too. `StreamingEnabled`, `StreamOutBehavior`, `Players.CharacterAutoLoads` and
  `Players.MaxPlayers` are readable. The Lune place test on the built `.rbxl` is therefore the
  authoritative check of §1.2's table; BootSmoke reports unreadable ones instead of failing.
- **String requires work in the engine** with the same semantics as Lune and luau-lsp
  (`./Sibling`, `../Up/Then`, `@self/Child` from an `init.luau`), so pure shared modules need no
  Lune shims.
- `Players.MaxPlayers = 49` builds into the place file (Rojo accepts it; Lune reads it back), but
  the live cap is the place's `serverSize` (currently 50 on all three places per the v2 Place
  resource) and must be set in Creator Hub or via `PATCH /cloud/v2/universes/{u}/places/{p}` by
  the owner or lead (brief v2 §5: 49).
- Task cost: a task create takes 0.4-2.3 s and a trivial task completes in about 3 s; the plan's
  "under 2 minutes" budget is comfortably met on the engine side.

## Decision for G0

Primary design stands (D15: owner builds and CI payloads as saved versions, tasks pinned to the
version ID, one lock and token bucket). Add `--inject` as the standing fast path for code-only
suites. The GitHub-Actions-with-a-secret fallback is **not** needed: the proxy path works; only
the key's permissions are missing, which the owner fixes in minutes. S1 is re-run (three commands,
`tools/cloud/README.md`) as soon as OS-0b is done, and `CHANGELOG.md` gets the first real CI version.
