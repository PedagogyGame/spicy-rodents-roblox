Pinsetter hardware and low traversal routes




Service side: open machinery, projecting ledges and the new floor mats.         Low view along the ball-return channel. Its opening is intentional.




Preserve the mechanics and openings

Eighteen bays contain setting decks, sweeps, elevators, distributors, reserve pins, gears, belts, motors, supports and bearings. Nine paired returns run
between them.

Use the separate collision asset

Do not put one large collision box around the machine bank. The low access ledges and return channels are intended for a small squirrel; fit must be tested
with the actual character.
